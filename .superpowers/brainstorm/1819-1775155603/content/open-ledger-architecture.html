Archive Layer (CAS — Content-Addressable Storage)
Verdict Hash
SHA-256 of full verdict + input params + kernel version. Immutable. Citable. Timestamped.
Public Ledger
Accumulated verdicts indexed by coordinates, watershed, date. The planetary audit trail.
Counter-Evidence API
Machine-readable verdict export. Embeddable in legal filings, journalism, activism.

Build Sequence

What ships, in what order, before the 2027 submission deadline

01
Structured Input Protocol
Replace CLI flags with a structured submission interface. Coordinates picker (map or manual). Parameter form with validation. Dependency classification (sovereign / external / attested). All still runs client-side in WASM.
Ship first
02
Verdict Archive (CAS Extension)
Extend existing SHA-256 CAS pipeline to store verdicts. Each verdict gets a permanent hash. Public manifest of all accumulated rulings. No database — flat CAS chunks, same architecture as kernel docs.
Ship first
03
Open API Ingest
USGS NWIS + EEA Waterbase connectors. User enters coordinates or river name → terminal pulls latest readings → runs audit. Dependency flag auto-set to "external". Graceful fallback to manual if API is down.
Stretch
04
Counter-Evidence Export
Machine-readable verdict export: JSON-LD, PDF audit report, embeddable widget. Designed for journalists, lawyers, activists, researchers. A verdict becomes a citable artifact with a permanent URL.
Stretch
Phase 2 Preview — The Kernel Commons

Once the ledger proves the infrastructure works on real data, the Kernel Commons opens: a submission protocol where others compile their own theories into WASM kernels. Soil scientists submit soil carbon auditors. Marine biologists submit ocean acidification models. Urban planners submit heat island assessors. Each new kernel inherits the same CAS provenance, the same verdict format, the same Axiomatic Core governance. The LatentCollider begins colliding foreign thought — theories you didn't write, producing chimeras you didn't predict.
