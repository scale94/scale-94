LEDGER TAB — VISUAL UPGRADE

Three visual layers that bring the Ledger to scale94 quality

Layer 1 — Hero Canvas
THE VERDICT MAP
A dark-tiles world map rendered on Canvas2D (reusing the d3-geo + topojson stack from EcocideTab's world map). As verdicts accumulate, they appear as pulsing markers — green for APPROVED, amber for CONDITIONAL, red for REJECTED/EMERGENCY_VETO. Each marker has a radial pulse ring that decays over time. The map is the first thing you see. It answers: "Where has the terminal issued rulings?" Empty at first — that emptiness is the invitation.
6 verdicts · 4 watersheds · 3 countries

Layer 2 — Execution Visualization
THE AUDIT CASCADE
When an audit runs, you don't just see a result card appear. You see the five Chrono-Actuary modules execute sequentially — each one sweeps a progress bar, reveals its contribution to the verdict, and the final ruling crystallizes at the end. The computation IS the visual. Staggered reveals (0.3s per module). Color shifts from teal (safe) through amber (stress) to red (arson).

Layer 3 — Choreography
PHASE-DRIVEN REVEAL
The Ledger tab doesn't load — it boots. Like every other tab on scale94:
Phase 0 (0.0s) — Map canvas fades in from black, graticule lines draw themselves
Phase 1 (0.8s) — Existing verdict markers pulse in (staggered 50ms per marker)
Phase 2 (1.5s) — Header text reveals with letter-spacing animation (like Feigenbaum title)
Phase 3 (2.0s) — Submission form slides up from below with blur(8px)→blur(0) transition
Phase 4 (on submit) — Audit cascade plays, then verdict marker drops onto the map with a particle burst
Precedent: ArtTab Jury Awakening · ScalingTab staggered card reveals · ClassifiedTab boot sequence
