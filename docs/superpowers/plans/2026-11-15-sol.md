# /SOL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the `/PRIVACY` nav slot with `/SOL`: a star the visitor winds by stirring until it snaps, whose ejections travel in true hours and land as an aurora or a single line, witnessed by the Quintessence Altar.

**Architecture:** All behaviour lives in small pure JS modules under `src/terminal/sol/` (physics, stir, star regions, camera, cloud clock) that take `dt` or `now` as arguments and are unit-tested. One full-screen WebGL2 fragment shader on the shared harness (`src/terminal/gl/useShaderCanvas`) draws the star, snap and aurora from uniforms those modules produce. Clouds persist in a bus-adjacent `localStorage` store modelled on `quintessence/spineStore.js`; the Altar reads a snapshot of it through `quintessence/periphery.js`.

**Tech Stack:** React 18, Vite, vitest (`npm test` = `vitest run`), WebGL2 GLSL ES 3.00 through `src/terminal/gl/`, Tailwind classes, ESLint (`npm run lint`, `--max-warnings 143`).

**Spec:** `docs/superpowers/specs/2026-11-15-sol-design.md`. Read it before any task. Section numbers below (§) refer to it.

## Review Focus

1. **Clock moved backward, or a stored launch time in the future**: status must clamp, never show negative progress or a cloud that landed before it launched. Test in Task 11.
2. **Corrupt or foreign JSON in `sol_clouds_v1`, or storage unavailable**: the store starts empty and the tab still works. Test in Task 12.
3. **Tab hidden for hours, then shown**: clouds are re-read from the wall clock on return; the star does not jump (dt clamp); a storm in progress shows at its current stage. Tests in Tasks 5 and 11.
4. **Pointer released off-canvas, `pointercancel`, or a second finger**: the stir ends as a release; no region stays held. Test in Task 8.
5. **Grab point rotates over the limb while held, or a stir starts at the very edge of the disc**: no NaN; the snap is treated as not facing the camera. Tests in Tasks 3 and 6.

### Task 5: `regions.js` — the star's active regions

**Files:** Create `src/terminal/sol/regions.js`; Test `src/terminal/sol/__tests__/regions.test.js`

**Interfaces:**
- Consumes: Task 3's constants and maps.
- Produces:
```js
export const MAX_REGIONS = 6, STAR_REGIONS = 4;
export const SELF_WIND_TURNS_PER_S = 0.005;   // tune: one region self-snaps in ~20 min; 4 staggered ≈ one per 5 min
export const OMEGA_EQ = 0.02;                 // rad/s at the equator, tune
omega(latRad): number                          // OMEGA_EQ * (1 - 0.265 * sin²(lat))  (25 d : 34 d)
// region: { id, lat, lon, starTurns, handTurns, held: boolean, born: 'star'|'hand' }
createStar(rng: () => number): { regions: Region[] }   // STAR_REGIONS regions, |lat| in 8°..35°, starTurns staggered across 0..TURNS_TO_SNAP
regionTurns(r): number                         // r.starTurns + Math.abs(r.handTurns)
stepStar(star, dtSeconds, { selfWind = true } = {}): SnapEvent[]
  // per region: lon += omega(lat)*dt; starTurns += SELF_WIND_TURNS_PER_S*dt when selfWind;
  // when !held, handTurns decays toward 0 with time constant SLIP_TAU_S;
  // any region with regionTurns >= TURNS_TO_SNAP snaps.
applyStir(star, regionId, turns): SnapEvent | null   // adds signed turns to handTurns; snaps if the threshold is crossed
grab(star, lat, lon): number                   // id of the nearest region within 0.25 rad, else a new 'hand' region (evicting the least-wound unheld 'hand' region at MAX_REGIONS); sets held
release(star, regionId): SnapEvent | null      // clears held; snaps if |handTurns| >= MIN_SNAP_TURNS, else null (it will slip)
// SnapEvent: { regionId, lat, lon, turns, energyErg, handedness: 'cw'|'ccw', origin: 'hand'|'star' }
//   handedness = sign of handTurns when |handTurns| >= MIN_SNAP_TURNS (positive → 'cw'), origin 'hand';
//   otherwise hemisphereHandedness(lat), origin 'star'.
//   After a snap: starTurns = 0, handTurns = 0, held = false; a 'hand'-born region is removed.
```

  - Slip: unheld region with `handTurns = 2`, `starTurns = 1`; after `stepStar(star, 8, { selfWind: false })`, `handTurns` is `2 / Math.E` within `1e-2` and `starTurns` is still `1`. A held region does not slip.
  - Rate invariance (Review Focus 3): 60 s simulated as 3600 steps of `1/60` and as 21600 steps of `1/360` give `starTurns`, `handTurns` and `lon` equal within `1e-6`.
  - `selfWind: false` leaves `starTurns` unchanged.
  - Cap: after seven `grab` calls at distinct points the star has at most `MAX_REGIONS` regions and no `'star'` region was evicted.
