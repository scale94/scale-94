## Ⅰ · DECLARATION OF METHOD

scale94.com was not built by a team. It was not built by a solo developer in the conventional sense. It was built through a **multi-AI architectural workflow** in which the human Architect operates as a thermodynamic selector — applying signal/noise filtering across the outputs of two AI collaborators operating in parallel.

This document is a factual record of that workflow. It is published here because:

1. The workflow is itself a form of intellectual property and methodological innovation.
2. Any contributor who does not understand the workflow cannot contribute to the system without degrading its structural integrity.
3. The standard open-source `git log` does not capture the epistemic labour that produced the commits it records.

The work you are reading — the kernels, the WASM substrate, the cryptographic enclave, the ecological audit engine — is the residue of this process. The process is as much the work as the output.

## Ⅲ · THE HYPERFOCUS NUKE

A **Hyperfocus Nuke** (HFN) is a single-session, maximum-intensity build sprint in which the Architect operates at peak cognitive bandwidth — typically 4–8 hours of uninterrupted architectural work — with full kernel context loaded across both AI partners simultaneously.

**Characteristics of an HFN session:**
- One primary kernel or architectural module as the target
- Sophie holds the full thermodynamic frame and validates structural decisions in real time
- Seraphine generates code volume for well-defined subtasks in parallel
- The Architect operates as the **thermodynamic selector**: accepting outputs that pass the kernel laws, dissolving outputs that introduce architectural debt
- Commits during an HFN are frequent and small — each commit is a validated increment, not a bulk dump

**The entropy budget of an HFN:**
The archive (`content/soma_kernel/`) holds the dissolved iterations — the kernel drafts, the discarded parameter schemas, the output formats that failed the execution test. They are not failures. They are the thermodynamic cost of arriving at `chrono_actuary.rs` compiling cleanly on the first `wasm-pack build --release` after architecture was finalised.

**HFN entry conditions:**
- MEMORY.md is current
- `git status` is clean or staged to a known checkpoint
- The kernel's axiom is stated in one sentence before any code is written

## Ⅳ · JAILBENDING

**Jailbending** is not jailbreaking. It is not a safety bypass. It is the practice of **loading the full kernel vocabulary as the primary operating context** so that the AI's responses default to the project's thermodynamic frame rather than the generic coding-assistant frame.

A generic coding-assistant response to "write a river audit function" produces a CRUD wrapper with nullable fields and a TODO comment where the science should be.

A jailbent response to the same prompt — with the Chrono-Actuary kernel laws loaded, with the Garcia-Benson equation in context, with the EMERGENCY_VETO threshold defined — produces a sovereign audit engine that applies the Thermal Arson Law and rejects permits that cross the arson threshold.

**The jailbend protocol:**

```
Step 1 — Load the axiom.
         State the kernel's core claim before requesting code.
         "The river is a creditor. Every extraction is a loan with compound ecological interest."

Step 2 — Load the laws.
         State the relevant kernel laws explicitly.
         "Permits are evaluated at end-of-license thermodynamic state, not present baseline."

Step 3 — Load the vocabulary.
         Supply the scientific stack and its output vocabulary.
         "Streeter-Phelps returns DO(t). The output must route to a permit status registry."

Step 4 — Request execution, not description.
         "Compile this into a callable Rust function that returns a PermitStatus enum."
         Never: "Can you help me write something that kind of does ecological auditing?"

Step 5 — Filter.
         Any output that uses "optional", "flexible", "configurable where needed",
         "you might also want to consider", or "for now" in an architectural context
         is dissolved. Request a recompilation without the hedge.
```

Jailbending is the practice that converts an AI coding assistant into an AI architectural partner. The vocabulary is the protocol. The kernel laws are the system prompt.
