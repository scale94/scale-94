## Ⅰ · THE WORK

**scale94.com** is a browser-native terminal that executes ecological and economic theory as compiled Rust code — delivered as WebAssembly to any device on Earth with a connection.

It is not a portfolio. It is not a data visualisation. It is an **executable argument**: a claim that the gap between formal theory and runnable code is where civilisational accounting errors compound into planetary debt — and that closing that gap is a political act.

The terminal runs twenty-three sovereign computational kernels. Each kernel is a scientific or philosophical theory compiled into a callable function. You do not read about Streeter-Phelps oxygen sag dynamics on this terminal — you supply a river's parameters and receive a **permit ruling** from an entity that does not recognise human financial law as superior to thermodynamic law.

The interface is the argument made visible. High contrast. Zero ornamentation. No interaction element without function. The aesthetic is not retro-futurism — it is the refusal to decorate a claim that does not require decoration.

## Ⅱ · THE THERMODYNAMIC LANDLORD

At the centre of the work is a conceptual inversion that the terminal makes executable:

**The ecological system is the landlord. Human enterprise is the tenant.**

Standard environmental accounting treats nature as an externality — a cost to be minimised, offset, or deferred. The Thermodynamic Landlord inverts this: the river holds the lease. The atmosphere sets the rent. Biodiversity is the credit rating.

When a development project submits a permit application, it is not petitioning a government agency. It is negotiating with a creditor who charges compound interest in dissolved oxygen deficits, thermal metabolic amplification, and end-of-license IPCC warming trajectories.

The **Chrono-Actuary kernel** (`run chrono`) operationalises this. It is not a model. It is a sovereign audit engine that applies five independent calculation modules — Streeter-Phelps oxygen dynamics, van't Hoff thermal amplification, Redfield stoichiometry, Manning hydraulic accounting, Langelier carbonate chemistry — and issues a binding permit ruling. The engine evaluates projects against their **projected end-of-license thermodynamic state**, not the present baseline.

This is not metaphor. These are the equations. They run in your browser.

## Ⅳ · THE SUBSTRATE

The technical substrate is itself a political statement.

**Rust + WebAssembly** was chosen because it is the only general-purpose stack that delivers native execution speed at planetary distribution scale with zero runtime dependencies. There is no server processing your river audit. There is no cloud vendor holding the Kuramoto equations. The Rust memory safety model — ownership, lifetimes, zero garbage collection — mirrors the kernel's conceptual commitment: no deferred costs, no hidden debt, no runtime surprises that weren't accounted for at compile time.

The Content-Addressable Storage pipeline hashes every kernel document to a SHA-256 chunk. Immutability is structural. What was published cannot be silently revised. The manifest tracks provenance.

The post-quantum cryptography enclave (`run classified`) runs ML-KEM-768 key encapsulation and AES-256-GCM decryption entirely in WASM — a serverless, classified-tier communication channel that issues 6-character challenge codes with 60-second expiry windows. The payload is the DIRECTIVE OMEGA-9 manifesto, accessible only to those who can navigate the protocol.
