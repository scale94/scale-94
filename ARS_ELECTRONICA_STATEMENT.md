## Ⅰ · THE WORK

**scale94.com** is a browser-native terminal that executes ecological, economic, and chemical theory as compiled Rust code — delivered as WebAssembly to any device on Earth with a connection.

It is not a portfolio. It is not a data visualisation. It is an **executable argument**: a claim that the gap between formal theory and runnable code is where civilisational accounting errors compound into planetary debt — and that closing that gap is a political act.

The terminal runs sixty-one sovereign computational kernels. Each kernel is a scientific or philosophical theory compiled into a callable function. You do not read about Streeter-Phelps oxygen sag dynamics on this terminal — you supply a river's parameters and receive a **permit ruling** from an entity that does not recognise human financial law as superior to thermodynamic law.

Among those sixty-one kernels is something that did not exist in prior computational art: an **Olfactory Collider**. The terminal synthesises fragrances it cannot smell. It fires a volatile molecule's 16-dimensional fingerprint against the kernel graph, traces a 16-beam interference pattern through the network topology, and — when coherence peaks — precipitates a named perfume accord. The output is a `TesseractCard`: chimera glyph, SARG decay arc, cryptographic vault. Not a recommendation engine. A phase transition.

The interface is the argument made visible. High contrast. Zero ornamentation. No interaction element without function. The aesthetic is not retro-futurism — it is the refusal to decorate a claim that does not require decoration.

## Ⅴ · THE SUBSTRATE

The technical substrate is itself a political statement.

**Rust + WebAssembly** was chosen because it is the only general-purpose stack that delivers native execution speed at planetary distribution scale with zero runtime dependencies. There is no server processing your river audit. There is no cloud vendor holding the Kuramoto equations. The Rust memory safety model — ownership, lifetimes, zero garbage collection — mirrors the kernel's conceptual commitment: no deferred costs, no hidden debt, no runtime surprises that weren't accounted for at compile time.

The Content-Addressable Storage pipeline hashes every kernel document to a SHA-256 chunk. Immutability is structural. What was published cannot be silently revised. The manifest tracks provenance. The chimera glyph's geometry is determined entirely by the SHA-256 hash of the precipitated accord's CAS molecular formula — no generative randomness, no server-side lookup, the glyph is an algebraic consequence of the chemistry.

The post-quantum cryptography enclave (`run classified`) runs ML-KEM-768 key encapsulation and AES-256-GCM decryption entirely in WASM — a serverless, classified-tier communication channel that issues 6-character challenge codes with 60-second expiry windows. The same cryptographic substrate seals the fragrance vault: ML-KEM-1024 + ML-DSA-87 + AES-256-GCM + BLAKE3 Merkle root — the Tesseract Protocol. The accord formula is stored; the key is earned.

The **Living Accord** bot is the social membrane: a Discord integration that accepts accord identity codes and returns deterministic note substitutions, extending the synthesis event into participatory space without breaking the cryptographic integrity of the sealed formula. The bot does not store user data. It derives. Each response is a pure function of the accord's hash.
