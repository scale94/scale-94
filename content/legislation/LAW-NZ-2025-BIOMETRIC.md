# Biometric Processing Privacy Code

## Biometric Processing Privacy Code 2025 (issued under Privacy Act 2020)

## Description

Code of practice regulating biometric information collection and processing. Introduces 'necessity test' requiring organizations to prove biometrics are necessary and proportionate. Bans emotion prediction and attention tracking except for safety purposes. Establishes transparency requirements but relies on self-assessment by organizations.

## Severity Rationale

> Applies to all organizations using biometric processing [+1], no criminal penalties but compliance orders possible [+0.5], irreversible biometric collection regulated but not prohibited [+0.5], explicit recognition of chilling effect on protests in Code text [+1], mission creep to emotion detection and attention tracking partially restricted [+0.5], oversight through Privacy Commissioner [+0], digital exclusion concerns acknowledged [+0.5]. Total: 3/5 (Medium)

## Implementation Notes

Came into force 3 November 2025. Grace period until 3 August 2026 for existing biometric systems. NZ Council for Civil Liberties strongly criticized for not going far enough, calling for ban on Remote Biometric Identification (RBI). Code recognizes 'chilling effect' on protests and rights to assembly. Māori stakeholders raised concerns about bias and discrimination. Consumer NZ criticized removal of 'informed consent and ability to opt out' safeguard from draft. Foodstuffs North Island facial recognition trial in supermarkets cited as concerning example.
