
## The Architecture of V-Cache Annihilation

This kernel abandons societal metaphor. It is a raw benchmark designed to weaponize the browser's WASM thread and flood the 5800X3D's physical L3 Cache. It utilizes a chaotic one-dimensional cellular automaton to generate maximum state mutations per cycle.

When the grid size and generations exceed the cache boundary, the system hits a thermodynamic wall.

### THE VARIABLES
* **--grid-size**: The number of contiguous cells allocated in RAM. (Default: 100,000)
* **--generations**: The number of lifecycle iterations to calculate instantly. (Default: 100)

If the cache pressure exceeds 500 Mega-Operations, the terminal enters a thread starvation risk state.
