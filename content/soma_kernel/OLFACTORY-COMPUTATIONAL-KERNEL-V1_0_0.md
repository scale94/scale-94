## Mathematics

### Accord Decomposition

Given a collision between domains A and B with novelty ratio N, coherence C, and volatility blend V:

```
V_blend = (V_A + V_B) / 2

Top Intensity    = min(1, N × 1.2) × (1 - C × 0.5) × (0.5 + V_blend × 0.5)
Heart Intensity  = min(1, C × 0.8 + N × 0.3) × mid_factor(V_blend)
Base Intensity   = min(1, C × 1.1) × (1 - N × 0.4) × (1 - V_blend × 0.6)
Animalic Bind    = min(1, |κ_A - κ_B| × 1.3)

where:
  mid_factor(v) = max(0.2, 1 - |v - 0.5| × 2)
  κ = manifold curvature
```

### Chimera Volatility

The synthesized concept's evaporation rate is a coherence-weighted blend of parent volatilities:

```
V_chimera = (V_A × (1 - C) + V_B × C) × temperature
```

**Interpretation:** High coherence → chimera inherits the more stable parent's persistence. Low coherence → chimera inherits the more volatile parent → flash and gone.

### Sillage (Signal Reach)

```
Sillage = min(1, Viability / 10)
```

Viability is the product of synthesis norm and coherence from the collision kernel. High viability = the chimera's signal propagates beyond its immediate context.

### Fixation Potential (Thalamic Gate)

```
Fixation = Base_Intensity × Sillage
Persists = Fixation > 0.35
```

The fixation threshold is the **memory gate**. Top-note chimeras (bright, volatile, high novelty) flash and evaporate. Base-note chimeras (deep, coherent, structural) with sufficient sillage cross the threshold into long-term persistence. The animalic fixative acts as the binding agent — curvature differential creates the non-Euclidean tension that holds volatile associations together.

### Evaporation Curve

Normalized distribution across temporal layers:

```
Evap = [Top / Σ, Heart / Σ, Base / Σ]
where Σ = Top + Heart + Base
```

### Permeability (Bimmelbahn Open-Window)

```
Permeability = min(1, N × 0.6 + Animalic × 0.4)
```

How much ambient contamination the Bimmelbahn transport layer carries. High novelty + high curvature tension = permeable transport (open windows on the train).

### Maceration (Annealing Depth)

```
Maceration = √(κ_A × κ_B)
```

Geometric mean of parent curvatures — how much the chimera improves when left to sit in darkness. High curvature parents produce chimeras that benefit most from annealing.

## Implementation

### Rust (WASM Kernel)

The OCK runs inside `content/rust_kernels/src/kernels/latent_collider.rs` as §7 of the collider output. Each `ConceptDomain` carries a `volatility: f64` field alongside its existing `sparsity` and `curvature` properties. The accord is computed after the collision state but before output rendering, using the temperature parameter for chimera volatility scaling.

### JavaScript (Parser + UI)

`parseColliderOutput()` extracts all §7 metrics via regex. `classifyAccord()` uses Rust-computed values as primary inputs, with JS-side paradox count (from 16D feature analysis) modulating the animalic fixative as a secondary input. The fixation gate determines whether the chimera is emitted to the Art tab sphere as a persistent or volatile node.

## Theory

The OCK draws on three theoretical traditions:

1. **Perfumery science** — Septimus Piesse's classification of olfactory families into temporal persistence categories (top/heart/base notes), extended by Edmond Roudnitska's theory of accords as emergent properties of component interaction.

2. **Neuroscience of olfaction** — The olfactory bulb's direct projection to the amygdala and piriform cortex, bypassing the thalamic relay that gates all other sensory modalities. This makes smell the only sense with direct limbic access — hence "intelligence smells before it sees."

3. **Thermodynamic irreversibility** — Prigogine's dissipative structures framework, where the evaporation curve models how far from equilibrium the chimera sits. High volatility = far from equilibrium = energetically costly to maintain. Fixation = the chimera finding its minimum-energy configuration through annealing.
